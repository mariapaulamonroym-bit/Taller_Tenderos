# Taller_Tenderos
# Este repositorio contiene el script en R desarrollado para el taller de la clase de Estadística de la Universidad del Rosario, en el que se analiza la penetración de internet entre tenderos de barrio en 10 ciudades de Colombia, a partir de la Encuesta a Tenderos (research-data.urosario.edu.co, DOI: 10.34848/JLP6C3). El script parte de la base a nivel de tienda (TenderosFU03_Publica.dta, cargada directamente desde este repositorio) y calcula el porcentaje de tenderos que usa internet agrupando por ciudad, por sector económico (usando las variables actG1 a actG11, que no son mutuamente excluyentes) y por la combinación de ambos, entregando además dos formatos de salida: una base larga (para visualizar en PowerBI) y una base extensa (para gráficos de dispersión por sector). Para correrlo solo se necesita tener instalados los paquetes dplyr, haven, tidyr y scales, y ejecutar taller_2.R de principio a fin en RStudio.
